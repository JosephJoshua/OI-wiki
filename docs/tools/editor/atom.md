Atom, the editor made by GitHub.

## Introduction

Atom is a free, open-source, cross-platform text editor developed by GitHub. It is written in JavaScript and built on Electron. One of its bigger drawbacks is poor performance.

???+ warning "Warning"
    On June 8, 2022, [GitHub announced it would sunset the Atom editor](https://github.blog/2022-06-08-sunsetting-atom/), and it archived Atom on December 15, 2022.
    If you still like Atom's interface, you can use [Pulsar](https://pulsar-edit.dev/) as a replacement. Its user interface is basically the same as Atom's, and its goal is to let users "keep their favorite editor alive"[^1].
