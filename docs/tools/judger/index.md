**Judging software** is software that scores your programs locally. Before submitting code to an OJ, you can use judging software to estimate how well your program will do.

This section covers the following judging software:

-   [Arbiter](./arbiter.md)
-   [CCR Plus](./ccr-plus.md)
-   [Cena](./cena.md)
-   [Lemon](./lemon.md)
