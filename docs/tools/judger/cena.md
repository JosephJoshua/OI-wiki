## Cena

**Cena** is an open-source judging tool written in Pascal by Liu Qishuai and Li Zixing. It is the most widely used local judging tool. Cena was first open-sourced on Google Code, but Google deleted the project for unknown reasons. You can still find Cena's official website on the [Web Archive](https://web.archive.org/web/20131023112258/http://code.google.com/p/cena/).

Cena's permission restrictions are not very strict: during testing, a program can read the test data files and get AC.

Cena's source code is hosted at [oi-archive/cena](https://github.com/oi-archive/cena).
