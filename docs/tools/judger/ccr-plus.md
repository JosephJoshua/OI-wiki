## CCR Plus

**CCR Plus** is an open-source, cross-platform judging environment for NOI-series contests. It is written with Qt and currently supports Windows and Linux.

The source code is hosted at [sxyzccr/CCR-Plus](https://github.com/sxyzccr/CCR-Plus).
