Search means enumerating a state space: we try every possibility to find the optimal solution, or to count the number of valid solutions.

There are many ways to optimize a search, such as shrinking the state space, changing the search order, and pruning.

Search is the foundation of some advanced algorithms. In OI, plain search is often a way to earn partial points, but very few problems can be fully solved with plain search alone.
