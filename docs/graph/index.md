**Graph theory** is a branch of mathematics, and graphs are its main object of study. A **graph** is a structure made of a set of vertices and edges, where each edge connects two vertices. Graphs are usually used to describe a particular relationship between things: a vertex represents a thing, and an edge between two vertices means the two things have this relationship.
