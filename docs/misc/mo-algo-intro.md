Mo's algorithm was proposed by Mo Tao. Before Mo Tao proposed it, the algorithm was already circulating in a small circle of top Codeforces competitors, but Mo Tao was the first to summarize it in detail. When he proposed it, he only analyzed ordinary Mo's algorithm, but through the collective wisdom of OIers and ACMers, Mo's algorithm has gained many extended versions.

Mo's algorithm solves a class of offline range query problems and is extremely widely applicable. With some extensions, it can also easily handle path queries on trees and support updates.
