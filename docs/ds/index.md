A data structure is a way of storing and organizing data in a computer. From small things like variables and arrays to big ones like segment trees and balanced binary search trees, they are all data structures.

Programs cannot run without data structures. Each data structure has its own strengths and weaknesses and can handle different problems. Choosing the right data structure for a specific problem can greatly improve a program's efficiency. So it is well worth learning many kinds of data structures.
