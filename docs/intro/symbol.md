This page sets out the recommended way to write mathematical symbols in **OI Wiki**, with some usage examples.

This page is revised from the symbol tables in [GB/T 3102.11-1993](https://openstd.samr.gov.cn/bzgk/gb/newGbInfo?hcno=3DE79450D562E62D41CB6E79FF411054), [ISO 80000-2:2019](https://www.iso.org/standard/64973.html) and *Concrete Mathematics*, so it is largely compatible with the notation of standard Chinese textbooks and with the notation commonly used in OI.

For the LaTeX code of each symbol, see [the source of this page](https://github.com/OI-wiki/OI-wiki/blob/master/docs/intro/symbol.md?plain=1)

## Mathematical logic

| No.                         | Symbol / expression       | Meaning / equivalent wording                     | Remarks and examples                                                                                                                                                                                       |
| --------------------------- | ------------------------- | ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <span id="n1.1">n1.1</span> | $p \land q$               | Conjunction of $p$ and $q$                       | $p$ and $q$.                                                                                                                                                                                               |
| <span id="n1.2">n1.2</span> | $p \lor q$                | Disjunction of $p$ and $q$                       | $p$ or $q$;<br>this "or" is inclusive: if at least one of $p$, $q$ is a true statement, then $p \lor q$ is true.                                                                                          |
| <span id="n1.3">n1.3</span> | $\lnot p$                 | Negation of $p$                                  | Not $p$.                                                                                                                                                                                                   |
| <span id="n1.4">n1.4</span> | $p \implies q$            | $p$ implies $q$;<br>if $p$ is true, then $q$ is true | $q \impliedby p$ means the same as $p \implies q$.                                                                                                                                                     |
| <span id="n1.5">n1.5</span> | $p \iff q$                | $p$ is equivalent to $q$                         | $(p \implies q) \land (q \implies p)$ means the same as $p \iff q$.                                                                                                                                        |
| <span id="n1.6">n1.6</span> | $(\forall~x \in A)~~p(x)$ | The statement $p(x)$ is true for every $x$ in $A$ | If the context makes clear which set $A$ is meant, the notation $(\forall~x)~~p(x)$ may be used.<br>$\forall$ is called the universal quantifier.<br>For the meaning of $x \in A$, see [n2.1](#n2.1).  |
| <span id="n1.7">n1.7</span> | $(\exists~x \in A)~~p(x)$ | There exists an $x$ in $A$ such that $p(x)$ is true | If the context makes clear which set $A$ is meant, the notation $(\exists~x)~~p(x)$ may be used.<br>$\exists$ is called the existential quantifier.<br>For the meaning of $x \in A$, see [n2.1](#n2.1).<br>$(\exists!~x)~~p(x)$ (the uniqueness quantifier) means that there is exactly one $x$ for which $p(x)$ is true.<br>$\exists!$ may also be written $\exists^1$. |

## Set theory

| No.                           | Symbol / expression                                   | Meaning / equivalent wording                      | Remarks and examples                                                                                                                                                                                                                                                                                                                  |
| ----------------------------- | ----------------------------------------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <span id="n2.1">n2.1</span>   | $x \in A$                                             | $x$ belongs to $A$; $x$ is an element of the set $A$ | $A \ni x$ means the same as $x \in A$.                                                                                                                                                                                                                                                                                         |
| <span id="n2.2">n2.2</span>   | $y \notin A$                                          | $y$ does not belong to $A$; $y$ is not an element of the set $A$ |                                                                                                                                                                                                                                                                                                                     |
| <span id="n2.3">n2.3</span>   | $\{x_1, x_2, \dots, x_n\}$                            | The set with elements $x_1, x_2, \dots, x_n$      | May also be written $\{x_i ~\vert~ i \in I\}$, where $I$ is an index set.                                                                                                                                                                                                                                                             |
| <span id="n2.4">n2.4</span>   | $\{x \in A ~\vert~ p(x)\}$                            | The set of all elements of $A$ for which the statement $p(x)$ is true | For example $\{x \in \textbf{R} ~\vert~ x \geq 5\}$;<br>if the context makes clear which set $A$ is meant, the notation $\{x ~\vert~ p(x)\}$ may be used (for example, $\{x ~\vert~ x \geq 5\}$ when only real numbers are under consideration)<br>$\vert$ may also be replaced by a colon, as in $\{x \in A : p(x)\}$.                    |
| <span id="n2.5">n2.5</span>   | $\operatorname{card} A$;<br>$\vert A\vert$;<br>$\# A$ | The number of elements of $A$; the cardinality of $A$ |                                                                                                                                                                                                                                                                                                                                   |
| <span id="n2.6">n2.6</span>   | $\varnothing$                                         | The empty set                                     | $\emptyset$ should not be used.                                                                                                                                                                                                                                                                                                       |
| <span id="n2.7">n2.7</span>   | $B \subseteq A$                                       | $B$ is contained in $A$; $B$ is a subset of $A$   | Every element of $B$ belongs to $A$.<br>$\subset$ may also be used with this meaning, but see the note in [n2.8](#n2.8).<br>$A \supseteq B$ means the same as $B \subseteq A$.                                                                                                                                                       |
| <span id="n2.8">n2.8</span>   | $B \subset A$                                         | $B$ is properly contained in $A$; $B$ is a proper subset of $A$ | Every element of $B$ belongs to $A$, and at least one element of $A$ does not belong to $B$.<br>If $\subset$ is given the meaning in [n2.7](#n2.7), then the symbol $\subsetneq$ should be used for [n2.8](#n2.8).<br>$A \supset B$ means the same as $B \subset A$.                                                 |
| <span id="n2.9">n2.9</span>   | $A \cup B$                                            | The union of $A$ and $B$                          | $A \cup B := \{x ~\vert~ x \in A \lor x \in B\}$;<br>for the definition of $:=$, see [n4.3](#n4.3)                                                                                                                                                                                                                                    |
| <span id="n2.10">n2.10</span> | $A \cap B$                                            | The intersection of $A$ and $B$                   | $A \cap B := \{x ~\vert~ x \in A \land x \in B\}$;<br>for the definition of $:=$, see [n4.3](#n4.3)                                                                                                                                                                                                                                   |
| <span id="n2.11">n2.11</span> | $\displaystyle \bigcup\limits_{i=1}^n A_i$            | The union of the sets $A_1, A_2, \dots, A_n$      | $\displaystyle \bigcup\limits_{i=1}^n A_i=A_1\cup A_2\cup \dots \cup A_n$;<br>$\displaystyle \bigcup\nolimits_{i=1}^n$, $\displaystyle \bigcup\limits_{i\in I}$, $\displaystyle \bigcup\nolimits_{i\in I}$ may also be used, where $I$ is an index set;<br>more generally, let $P(i)$ be a statement about $i$; then $\displaystyle \bigcup_{P(i)} A_i$ denotes the union of the $A_i$ over all $i$ for which $P(i)$ is true |
| <span id="n2.12">n2.12</span> | $\displaystyle \bigcap\limits_{i=1}^n A_i$            | The intersection of the sets $A_1, A_2, \dots, A_n$ | $\displaystyle \bigcap\limits_{i=1}^n A_i=A_1\cap A_2\cap \dots \cap A_n$;<br>$\displaystyle \bigcap\nolimits_{i=1}^n$, $\displaystyle \bigcap\limits_{i\in I}$, $\displaystyle \bigcap\nolimits_{i\in I}$ may also be used, where $I$ is an index set;<br>more generally, let $P(i)$ be a statement about $i$; then $\displaystyle \bigcap_{P(i)} A_i$ denotes the intersection of the $A_i$ over all $i$ for which $P(i)$ is true |
| <span id="n2.13">n2.13</span> | $A \setminus B$                                       | The difference of $A$ and $B$                     | $A \setminus B = \{x ~\vert~ x \in A \land x \notin B\}$;<br>$A - B$ should not be used;<br>when $B$ is a subset of $A$, $\complement_A B$ may also be used; if the context makes clear which set $A$ is meant, $A$ may be omitted.<br>When there is no ambiguity, $\overline{B}$ may also be used for the complement of the set $B$. |
| <span id="n2.14">n2.14</span> | $(a, b)$                                              | The ordered pair $a$, $b$;<br>the ordered couple $a$, $b$ | $(a, b) = (c, d)$ if and only if $a = c$ and $b = d$.                                                                                                                                                                                                                                                                       |
| <span id="n2.15">n2.15</span> | $(a_1, a_2, \dots, a_n)$                              | Ordered $n$-tuple                                 | See [n2.14](#n2.14).                                                                                                                                                                                                                                                                                                                  |
| <span id="n2.16">n2.16</span> | $A \times B$                                          | The Cartesian product of the sets $A$ and $B$     | $A \times B = \{(x, y) ~\vert~ x \in A \land y \in B\}$.                                                                                                                                                                                                                                                                              |
| <span id="n2.17">n2.17</span> | $\displaystyle \prod\limits_{i=1}^{n} A_i$            | The Cartesian product of the sets $A_1, A_2, \dots, A_n$ | $\displaystyle \prod\limits_{i=1}^{n} A_i=\{(x_1, x_2, \dots, x_n) ~\vert~ x_1 \in A_1, x_2 \in A_2, \dots, x_n \in A_n\}$;<br>$A \times A \times \dots \times A$ is written $A^n$, where $n$ is the number of factors in the product;<br>for another use of this symbol, see [n6.8](#n6.8)                                  |
| <span id="n2.18">n2.18</span> | $\mathrm{id}_A$                                       | The diagonal of $A\times A$                       | $\mathrm{id}_A=\{(x, x)~\vert~x\in A\}$;<br>if the context makes clear which set $A$ is meant, $A$ may be omitted.                                                                                                                                                                                                                    |
| <span id="n2.19">n2.19</span> | $\mathbf{1}_A$                                        | Indicator function                                | $\mathbf{1}_A(a)=[a\in A]$; for the definition of $[\cdot]$, see [n6.24](#n6.24).                                                                                                                                                                                                                                                     |
| <span id="n2.20">n2.20</span> | $\mathcal{P}(A)$;<br>$2^A$                            | Power set                                         | $\mathcal{P}(A)=\{S:S\subseteq A\}$                                                                                                                                                                                                                                                                                                   |

## Standard number sets and intervals

| No.                           | Symbol / expression | Meaning / equivalent wording       | Remarks and examples                                                                                                                                                                        |
| ----------------------------- | ------------ | ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <span id="n3.1">n3.1</span>   | $\mathbf{N}$ | The set of natural numbers                | $\mathbf{N} = \{0, 1, 2, 3, \dots\}$;<br>$\mathbf{N}^* = \mathbf{N}_+ = \{1, 2, 3, \dots\}$;<br>other restrictions can be added like this: $\mathbf{N}_{> 5} = \{n \in \mathbf{N} ~\vert~ n > 5\}$;<br>$\mathbb{N}$ may also be used. |
| <span id="n3.2">n3.2</span>   | $\mathbf{Z}$ | The set of integers                       | $\mathbf{Z}^* = \mathbf{Z}_+ = \{n \in \mathbf{Z} ~\vert~ n \ne 0\}$;<br>other restrictions can be added like this: $\mathbf{Z}_{> -3} = \{n \in \mathbf{Z} ~\vert~ n > -3\}$;<br>$\mathbb{Z}$ may also be used.                      |
| <span id="n3.3">n3.3</span>   | $\mathbf{Q}$ | The set of rational numbers               | $\mathbf{Q}^* = \mathbf{Q}_+ = \{r \in \mathbf{Q} ~\vert~ r \ne 0\}$;<br>other restrictions can be added like this: $\mathbf{Q}_{< 0} = \{r \in \mathbf{Q} ~\vert~ r < 0\}$;<br>$\mathbb{Q}$ may also be used.                        |
| <span id="n3.4">n3.4</span>   | $\mathbf{R}$ | The set of real numbers                   | $\mathbf{R}^* = \mathbf{R}_+ = \{x \in \mathbf{R} ~\vert~ x \ne 0\}$;<br>other restrictions can be added like this: $\mathbf{R}_{> 0} = \{x \in \mathbf{R} ~\vert~ x > 0\}$;<br>$\mathbb{R}$ may also be used.                        |
| <span id="n3.5">n3.5</span>   | $\mathbf{C}$ | The set of complex numbers                | $\mathbf{C}^* = \mathbf{C}_+ = \{z \in \mathbf{C} ~\vert~ z \ne 0\}$;<br>$\mathbb{C}$ may also be used.                                                                                                 |
| <span id="n3.6">n3.6</span>   | $\mathbf{P}$ | The set of (positive) primes              | $\mathbf{P} = \{2, 3, 5, 7, 11, 13, 17, \dots\}$;<br>$\mathbb{P}$ may also be used.                                                                                                                     |
| <span id="n3.7">n3.7</span>   | $[a, b]$     | The closed interval from $a$ to $b$       | $[a, b] = \{x \in \mathbf{R} ~\vert~ a \leq x \leq b\}$.                                                                                                                                    |
| <span id="n3.8">n3.8</span>   | $(a, b]$     | The interval from $a$ to $b$, open on the left and closed on the right | $(a, b] = \{x \in \mathbf{R} ~\vert~ a < x \leq b\}$;<br>$(-\infty, b] = \{x \in \mathbf{R} ~\vert~ x \leq b\}$.                                                                            |
| <span id="n3.9">n3.9</span>   | $[a, b)$     | The interval from $a$ to $b$, closed on the left and open on the right | $[a, b) = \{x \in \mathbf{R} ~\vert~ a \leq x < b\}$;<br>$[a, +\infty) = \{x \in \mathbf{R} ~\vert~ a \leq x\}$.                                                                            |
| <span id="n3.10">n3.10</span> | $(a, b)$     | The open interval from $a$ to $b$         | $(a, b) = \{x \in \mathbf{R} ~\vert~ a < x < b\}$;<br>$(-\infty, b) = \{x \in \mathbf{R} ~\vert~ x < b\}$;<br>$(a, +\infty) = \{x \in \mathbf{R} ~\vert~ a < x\}$.                          |

## Relations

| No.                           | Symbol / expression  | Meaning / equivalent wording      | Remarks and examples                                                                                          |
| ----------------------------- | -------------------- | --------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| <span id="n4.1">n4.1</span>   | $a = b$              | $a$ equals $b$                    | $\equiv$ is used to stress that an equation is an identity<br>for another meaning of this symbol, see [n4.18](#n4.18). |
| <span id="n4.2">n4.2</span>   | $a \ne b$            | $a$ is not equal to $b$           |                                                                                                               |
| <span id="n4.3">n4.3</span>   | $a := b$             | $a$ is defined as $b$             | See [n2.9](#n2.9),[n2.10](#n2.10)                                                                             |
| <span id="n4.4">n4.4</span>   | $a \approx b$        | $a$ is approximately equal to $b$ | Does not rule out equality.                                                                                   |
| <span id="n4.5">n4.5</span>   | $a \simeq b$         | $a$ is asymptotically equal to $b$ | For example:<br>as $x\to a$, $\dfrac{1}{\sin(x-a)} \simeq \dfrac{1}{x-a}$;<br>for the meaning of $x \to a$, see [n4.15](#n4.15). |
| <span id="n4.6">n4.6</span>   | $a \propto b$        | $a$ is proportional to $b$        | $a \sim b$ may also be used.<br>$\sim$ is also used for equivalence relations.                               |
| <span id="n4.7">n4.7</span>   | $M \cong N$          | $M$ is congruent to $N$           | When $M$ and $N$ are point sets (geometric figures).<br>This symbol is also used for isomorphism of algebraic structures. |
| <span id="n4.8">n4.8</span>   | $a < b$              | $a$ is less than $b$              |                                                                                                               |
| <span id="n4.9">n4.9</span>   | $b > a$              | $b$ is greater than $a$           |                                                                                                               |
| <span id="n4.10">n4.10</span> | $a \leq b$           | $a$ is less than or equal to $b$  |                                                                                                               |
| <span id="n4.11">n4.11</span> | $b \geq a$           | $b$ is greater than or equal to $a$ |                                                                                                             |
| <span id="n4.12">n4.12</span> | $a \ll b$            | $a$ is much less than $b$         |                                                                                                               |
| <span id="n4.13">n4.13</span> | $b \gg a$            | $b$ is much greater than $a$      |                                                                                                               |
| <span id="n4.14">n4.14</span> | $\infty$             | Infinity                          | This symbol is **not** a number.<br>$+\infty$, $-\infty$ may also be used.                                    |
| <span id="n4.15">n4.15</span> | $x \to a$            | $x$ tends to $a$                  | Usually appears in limit expressions.<br>$a$ may also be $\infty$, $+\infty$, $-\infty$.                      |
| <span id="n4.16">n4.16</span> | $m \mid n$           | $m$ divides $n$                   | For integers $m$, $n$:<br>$(\exists~k \in \mathbf{Z})~~m\cdot k = n$.                                         |
| <span id="n4.17">n4.17</span> | $m \perp n$          | $m$ and $n$ are coprime           | For integers $m$, $n$:<br>$(\nexists~k \in \mathbf{Z}_{>1})~~(k \mid m) \land (k \mid n)$;<br>for another use of this symbol, see [n5.2](#n5.2) |
| <span id="n4.18">n4.18</span> | $n \equiv k \pmod m$ | $n$ is congruent to $k$ modulo $m$ | For integers $n$, $k$, $m$:<br>$m \mid (n - k)$;<br>do not confuse this with the use mentioned in [n4.1](#n4.1). |

## Coordinate systems

This section covers some coordinate systems in three-dimensional space. The point $\mathrm{O}$ is the **origin** of the coordinate system. Every point $\mathrm{P}$ is determined by its **position vector** from the origin $\mathrm{O}$ to the point $\mathrm{P}$.

| No.                           | Coordinates               | Position vector and its differential                                                                                                                                                                                         | Name of coordinates | Remarks                                                                                                                                                                                                                                                                |
| ----------------------------- | ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <span id="n13.1">n13.1</span> | $x$, $y$, $z$             | $\boldsymbol{r} = x \boldsymbol{e}_x + y \boldsymbol{e}_y + z \boldsymbol{e}_z$;<br>$\mathrm{d}\boldsymbol{r} = \mathrm{d}x~\boldsymbol{e}_x + \mathrm{d}y~\boldsymbol{e}_y + \mathrm{d}z~\boldsymbol{e}_z$                  | Cartesian coordinates | The basis vectors $\boldsymbol{e}_x$, $\boldsymbol{e}_y$, $\boldsymbol{e}_z$ form a right-handed orthonormal system; see [Figure 1](#figure-1) and [Figure 4](#figure-4).<br>The basis vectors may also be written $\boldsymbol{e}_1$, $\boldsymbol{e}_2$, $\boldsymbol{e}_3$ or $\boldsymbol{i}$, $\boldsymbol{j}$, $\boldsymbol{k}$, and the coordinates may also be written $x_1$, $x_2$, $x_3$ or $i$, $j$, $k$. |
| <span id="n13.2">n13.2</span> | $\rho$, $\varphi$, $z$    | $\boldsymbol{r} = \rho~\boldsymbol{e}_{\rho} + z~\boldsymbol{e}_z$;<br>$\mathrm{d}\boldsymbol{r} = \mathrm{d}\rho~\boldsymbol{e}_{\rho} +\rho~\mathrm{d}\varphi~\boldsymbol{e}_{\varphi} + \mathrm{d}z~\boldsymbol{e}_z$     | Cylindrical coordinates | $\boldsymbol{e}_{\rho}(\varphi)$, $\boldsymbol{e}_{\varphi}(\varphi)$, $\boldsymbol{e}_z$ form a right-handed orthonormal system; see [Figure 2](#figure-2).<br>If $z = 0$, then $\rho$ and $\varphi$ are polar coordinates in the plane.                                                                 |
| <span id="n13.3">n13.3</span> | $r$, $\vartheta$, $\varphi$ | $\boldsymbol{r} = r \boldsymbol{e}_r$;<br>$\mathrm{d}\boldsymbol{r} = \mathrm{d}r~\boldsymbol{e}_r + r~\mathrm{d}\vartheta~\boldsymbol{e}_{\vartheta} + r~\sin\vartheta~\mathrm{\mathrm{d}}\varphi~\boldsymbol{e}_{\varphi}$ | Spherical coordinates | $\boldsymbol{e}_r(\vartheta, \varphi)$, $\boldsymbol{e}_{\vartheta}(\vartheta, \varphi)$, $\boldsymbol{e}_{\varphi}(\varphi)$ form a right-handed orthonormal system; see [Figure 3](#figure-3).                                                                    |

## Scalars and vectors

In this section, the basis vectors are written $\boldsymbol{e}_1$, $\boldsymbol{e}_2$, $\boldsymbol{e}_3$. Many of the ideas in this section extend to $n$-dimensional space.

Scalars and vectors themselves do not depend on the choice of coordinate system, but each scalar component of a vector does.

Given basis vectors $\boldsymbol{e}_1$, $\boldsymbol{e}_2$, $\boldsymbol{e}_3$, every vector $\boldsymbol{a}$ can be written as $\boldsymbol{a}=a_1\boldsymbol{e}_1+a_2\boldsymbol{e}_2+a_3\boldsymbol{e}_3$, where $a_1$, $a_2$ and $a_3$ are uniquely determined scalars, called the "coordinates" of the vector with respect to this basis; $a_1\boldsymbol{e}_1$, $a_2\boldsymbol{e}_2$ and $a_3\boldsymbol{e}_3$ are called the component vectors of the vector with respect to this basis.

This section only considers Cartesian (orthogonal) coordinates in ordinary space. Cartesian coordinates are written $x$, $y$, $z$ or $a_1$, $a_2$, $a_3$ or $x_1$, $x_2$, $x_3$.

In this section, all indices $i$, $j$, $k$ range from $1$ to $3$.

## Special functions

In this section, $z$, $w$ are complex numbers, $k$, $n$ are natural numbers, and $k\leq n$.

| No.                           | Symbol / expression      | Meaning / equivalent wording       | Remarks and examples                                                                                                                                                                                                                                                            |
| ----------------------------- | ------------------------ | ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <span id="n15.1">n15.1</span> | $\gamma$                 | The Euler–Mascheroni constant      | $\displaystyle \gamma=\lim\limits_{n\to\infty}\left(\sum\limits_{k=1}^n\frac{1}{k}-\ln n\right)= 0.577~215~6 \dots$.                                                                                                                                                            |
| <span id="n15.2">n15.2</span> | $\Gamma(z)$              | The gamma function                 | $\displaystyle\Gamma(z)=\int\limits_0^{\infty}t^{z-1}\mathrm{e}^{-t}\mathrm{d}t\quad (\operatorname{Re}z>0)$;<br>$\Gamma(n+1)=n!$.                                                                                                                                              |
| <span id="n15.3">n15.3</span> | $\zeta(z)$               | The Riemann zeta function          | $\displaystyle\zeta(z)=\sum\limits_{n=1}^{\infty}\frac{1}{n^z}\quad (\operatorname{Re}z>1)$.                                                                                                                                                                                    |
| <span id="n15.4">n15.4</span> | $\operatorname{B}(z, w)$ | The beta function                  | $\displaystyle\operatorname{B}(z, w)=\int\limits_0^1 t^{z-1}(1-t)^{w-1}\mathrm{d}t\quad (\operatorname{Re} z>0$, $\operatorname{Re} w>0)$;<br>$\operatorname{B}(z, w)=\dfrac{\Gamma(z)\Gamma(w)}{\Gamma(z+w)}$;<br>$\dfrac{1}{(n+1)\operatorname{B}(k+1, n-k+1)}=\dbinom{n}{k}$. |
