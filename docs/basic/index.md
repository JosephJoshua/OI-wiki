An **algorithm**, as the name suggests, is a method of computation. Algorithms are usually used to solve specific computational tasks. Unlike programs, which can run directly on a computer, algorithms are described mathematically and focus on ideas. You can think of them as abstract programs. The same algorithm can be implemented in many different ways, and two different programs may use the same algorithm.

This chapter introduces some basic algorithms. When a computational task is general enough to show up in all kinds of problems, the algorithm that solves it gets used by many other algorithms, which makes it both important and fundamental. Also, the more general an algorithm is, the simpler it usually is, and the closer it is to an idea rather than a program. The algorithms in this chapter are elegant and fun, and they often come up again in the more advanced topics later on.
